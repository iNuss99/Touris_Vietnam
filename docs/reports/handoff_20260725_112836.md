# Handoff Report: CRM Leads Management Upgrade
**Date:** 25/07/2026
**Project:** Touris_Vietnam

## 1. Mục tiêu Session
Nâng cấp module quản lý Khách hàng tiềm năng (Leads) cho hệ thống CRM:
- Tích hợp hệ thống chấm điểm (Lead Scoring) tự động.
- Cải thiện giao diện quản lý danh sách Leads (Thêm tính năng sắp xếp dữ liệu).
- Xây dựng bảng biểu phân tích và phân loại khách hàng (Customer Segmentation).

## 2. Các thay đổi kỹ thuật (Technical Changes)

### 2.1. Backend (Node.js/Express)
- **Database Schema**: Thêm 2 cột mới vào bảng `leads`:
  - `score` (INT): Điểm số đánh giá mức độ tiềm năng.
  - `grade` (VARCHAR): Phân loại (HOT, WARM, COLD) dựa trên điểm số.
- **API `POST /api/leads`** (`src/server.js`): 
  - Tích hợp thuật toán `calculateLeadScore()` trực tiếp vào API tạo Lead mới. 
  - Đảm bảo 100% Leads mới đổ về từ Form hoặc Chatbot đều được tự động chấm điểm và gán nhãn ngay lập tức theo kịch bản kinh doanh.
- **Migration & Cleanup**:
  - Đã chạy script migration thành công cho 126 leads cũ trong cơ sở dữ liệu.
  - Đã xóa bỏ các file script dùng một lần (`migration.js`, `calculate_existing.js`, `update_names.js`, `seed_leads.js`) để dọn dẹp không gian dự án.

### 2.2. Frontend (React/Vite)
- **Dashboard - Danh sách Leads (`LeadsView.jsx`, `index.jsx`)**:
  - Bổ sung cột hiển thị **Chất lượng** (Grade & Score).
  - Tích hợp tính năng **Sắp xếp (Sorting)** cho các cột: Thời gian, Chất lượng, và Trạng thái.
- **Dashboard - Báo cáo & Phân tích (`ReportsView.jsx`)**:
  - Chuyển đổi và nâng cấp màn hình báo cáo, thêm chức năng **Customer Segmentation**.
  - Bổ sung 4 biểu đồ tự động (sử dụng thư viện `recharts`):
    1. **Pie Chart**: Tỷ trọng phân loại Lead (HOT/WARM/COLD).
    2. **Pie Chart**: Phân bổ Hạng dịch vụ (VIP/PREMIUM/ECONOMY).
    3. **Bar Chart**: Top 5 Điểm đến được quan tâm nhất.
    4. **Bar Chart**: Nhu cầu quy mô đoàn khách (1, 2-4, 5+ khách).
  - Dữ liệu biểu đồ được tính toán tự động bằng `useMemo` từ danh sách `leads` hiện tại.
